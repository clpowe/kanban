# kanban

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run dev
```

The default dev command starts both the Cloudflare Worker API on
`http://localhost:8787` and the Vite client on `http://localhost:3000`.

This project was created using `bun init` in bun v1.3.10. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
